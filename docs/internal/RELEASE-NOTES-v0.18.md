# v0.18.0 - Refactor Anything, Render Anything & Feel Everything

This release is about changing a project without fear, saying what the whole world looks like in words, and making a hit feel like something. **Refactor Anything**: a verb that moves carries a forwarding address, a rename lists what it touches before it touches it, an object's states are a variable, and a scene, a file or a hand-written `match` machine opens as rows byte-exact. **Render Anything**: the environment, the sky, the surface, the camera, twenty blend modes, a post stack and seven crisp shape nodes, each one a row and none of them a property name. **Feel Everything**: the Feedback Player, a whole beat of feedback written down and played by name, beside the clocks, wounds, music, prompts, waves and targeting a finished game is made of. Underneath: the resting toolbar, a manual you search inside Godot, the editor reading its own source, and a plugin measured on a project ten times this one.

## Highlights

- **The refactor contract.** A moved verb carries a forwarding address and the sheet head counts the rows that have one; **Migrate…** shows every rewrite in both languages and proves each one twice before it lands. Renames list what they touch first, a pack update is a proposal with a tri-list, a verb the vocabulary has lost has an honest exit, and a merge's doubled local and half-finished file are named rather than met at runtime. All of it is reachable from a command line, so CI can ask the same questions.

- **An object's own state is a variable.** `Declare states…` once, then **Is in / Go to / On entering** as rows, a live band in play mode showing the state the running game is in, and the Trail saying what the machine just did. A hand-written `match state:` machine opens as those rows and saves back byte-exact. Nouns in a comment are doors, and one search knows what the sheet knows.

- **Scenes and files, in the engine's own words.** Layouts on top of the running game, `%name` as a word, the spawn sentence in three dimensions, the tree announcing arrivals, and saving what a player built behind a data-only trust line. `user://` and `res://` are taught at the path field, guards are written into the emitted line, tables the engine reads itself, and user content arrives through two doors as data, never code.

- **Render anything.** Twenty-one words for the world's look on any `WorldEnvironment`, the sky, the surface and the lens; the Camera shelf finished in 2D and 3D; the viewport and how the game meets the screen; the light and the shader dial as the OBJECT; twenty blend modes as one row; a post stack with looks you save from the live game; and a chromatic shake beside the kick that stays. Layers speak the project's own names, and the Doctor knows the silent ways each of these does nothing.

- **Stroke, cap and dash.** Seven shape nodes in 2D drawn through one distance-field shader, crisp at any zoom with nothing tessellated on the CPU, and the Inspector that goes with them: a unit drawer where the number never moves, lists that read as cards, icon toggles, show-if groups, a link between fields and a handle you can drag in the viewport.

- **Beat, bump and broadcast.** The **Feedback Player** is a node whose Inspector is a list of cards, every gesture in it a row by label; a **Moment** block plays a whole beat by name; shakers on groups; springs on any property; and a stopped player, a settled spring bank and a parked tick cost zero frame time. All fifty-four of its verbs open as verbs.

- **Clock, wound and chorus.** Cooldowns, countdowns and stopwatches as clocks with names on them; the clock a pause holds and the first time in a save; music that follows the game, prompts, speech and animation; ownership, damage kinds and what a wound leaves behind; **Targeting** in 2D and 3D with lock-on, cycling, aim assist and the moment a target is lost; tilemaps you can ask what they are made of; a whole wave spawned in one row; and a seeded grid that walks itself into a level.

- **The resting toolbar.** The top strip went from twenty-one controls over 137 commands to seven that never wrap: one Menu, three icons, one play button holding every way to run, Quick add and a chevron. Nothing was removed and every key is unchanged. Autocomplete is one seam and one popup in every name field, and Quick add reads a whole typed sentence.

- **Playing together, and collisions written down.** Godot's high-level multiplayer in sentences, byte-exact both ways, with the four silent networking mistakes caught by the Doctor. Collisions as the step something changed, the touch with a filter on it, who sees whom, spawning said in sentences, destroying without ghosts, crowds counted by the tree, and the four crashes a spawn can cause found before the game runs.

- **The API is the vocabulary.** Every call and property write on a known class reads as a row with zero authoring, curated tables upgrade them in place, a pack can teach the reader the lines its verbs are written as, and the three reading layers are written down with the verbatim ledger of what nothing claims. The sheet went quiet about what is wrong: findings are an amber state, never a widget in a row.

- **The Manual, and the editor reading itself.** One search over the guides, the addon guides and the engine's own words, docked beside the sheet and following what you select; every row a door both ways; a guide's example lands in your sheet; learning paths; tutorials you do rather than read; and What's new. All fifteen shapes Godot can be extended in are starter sheets, and the plugin's own source opens as event sheets: 1,089 files, 1,087 of them at zero script blocks, 89.9% of those rows in the sheet's own words.

- **Performance, measured.** On a fabricated project ten times this one (1,000 scripts, 300 scenes, 100 shaders, every pack installed): enabling the plugin costs 270 ms, the first sheet tab 2,310 ms, one keystroke in a completing field 2.2 ms, a 4,000-line script opens in 7.4 s, and eleven such budgets are tests. Opening a script is about 7x faster, the compiler is off the boot path, the canvas redraws a big pack six times faster, and stopped behaviors cost zero frame time.

- **The starting value says which kind it is.** `default_word:` and `default_code:` beside `default:`, so a pack's row opens on a word its template quotes or on code it writes verbatim; forty-two dropdowns that held a word they never showed, five that opened on the wrong word and eighteen shipped rows that did not compile with the values they open on are fixed, and a gate compiles every pack's default row in its host. The Doctor learned which folders are yours.

**Quality:** every feature landed suite-green with byte-exact round-trip gates and `drifted=0` across all **138 packs** and **28 showcases**; the pack builders are held against the shipped packs, every pack's default rows compile in their host, and the Doctor, the standing-contract gate and the translation harvest are all CI gates. The suite stands at **27,176 assertions across 806 test files**, run sharded on Windows and serially on Linux on every push. Verified on Godot 4.7 stable.
