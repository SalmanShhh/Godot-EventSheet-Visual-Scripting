# v0.17.0 - Adopt Anything, Read Anything & Ask Why

This release is about the code you already have and the words you read it in. **Adopt Anything**: opening a hand-written `.gd` was measured at 88.1% verbatim code blocks; it is now **zero** - every code line across 206 real files arrives as structure, byte-exact on every one, and your own classes are pickable vocabulary with no setup at all. **Read Anything**: rows read like sentences with the values in bold, state machines read like state machines, identity rows stand apart as bars, and every guide - the plugin's, the modules', the packs' - opens inside the editor with figures that draw themselves from real rows. **Ask Why**: hit counts in the gutter, a panel that says why an event did not fire, Test Sheets that run headless and print a verdict, a Doctor that names the value nothing ever saves, and On Failure / On Success as real triggers. The pack count grows from 76 to **91**, the native vocabulary passes **1,200 ACEs**, the nine editor languages carry over 1,700 keys each, everything still compiles to plain typed GDScript with zero runtime dependency, and every pack round-trips byte-for-byte.

## Highlights

- **A hand-written `.gd` opens as rows - all of it.** Measured over 206 hand-written files in this repo (ordinary style-guide GDScript nobody wrote for a demo), 88.1% of code lines were landing in verbatim blocks; the number is now zero, gated by a test that opens REAL sources rather than fixtures. Four spelling-level bugs each reverted a whole file (the style guide's two blank lines between functions, an explicit `: Variant` parameter, a typed-collection return, a `#` note above a function). The residue turned out to be structure nobody had split: **one statement is one action** - selectable, disableable, draggable - with comment runs as real comment rows, collection literals as **Declare** rows (body and file scope) whose entries edit in place or through an Add / Edit / Remove Entry menu, and split rules that never cut inside a class body, a string, or an open bracket. Beginner-style files (`:=` variables, untyped lifecycle headers, a `match state:` in `_physics_process`) round-trip byte-exact like everything else, and a compiler bug that injected a provider member into a file whose comments merely discussed the convention is fixed. Every lift is still gated by a byte-exact recompile: what the model cannot reproduce degrades to a verbatim block instead of corrupting your file.

- **Your own classes are vocabulary, with zero setup.** The picker's object page gained a **Your Project** section listing the classes and autoloads your game declares: methods reflected as Actions (void), Conditions (bool) and Expressions (a value), properties as Set / Get pairs, signals as triggers, each emitting the plain call you would have written. Reflected verbs carry a row sentence and infer their widgets from name and type, and each one says where its name came from - "inferred from the script, not curated" - so you can disagree: rename, recategorize or hide a verb through a project override catalog that never touches your source (or bake the overrides in as `## @ace_*` comments on request). A bare `$Inventory.add_item("potion", 3)` that reaches a sheet offers **Convert to Add Item** when it matches exactly one of your verbs, **Sheet > Name Raw Calls** sweeps a whole sheet the same way against engine classes, your scripts and installed packs, and the orphaned-verb Doctor check now names the member you probably renamed it to. An adversarial review of this stack found 21 defects in green-suite code; all are fixed.

- **Rows read like Construct's.** Every substituted parameter draws **bold** inside its sentence, composing with the typed value tints, and the hand-authored layer on top marks 42 built-in display texts and 36 packs' featured verbs (`Start boost **{id}** at **{multiplier}**x`) l10n-safely. Statements read as sentences (`Add wave[1] to score`), calls read as Object then Verb, and hovering any of them shows the exact GDScript line. **Reading Mode** turns the Simple Mode pill into a lens that shows body comments as italic captions. State machines read like state machines: `◆ State: patrol` headers keyed on the method shape, Every Physics Tick as that trigger's name everywhere, a lifted enum + match machine landing in the nested state-machine shape with guards humanized and an ƒ badge on computed checks. Identity rows are **bars**: the enum block reads `State is one of PATROL, CHASE or FLEE` closed and a list open, Class setup is an inheritance breadcrumb with a facts dropdown, Host binding wears its class icon. Cells **wrap by word** instead of clipping (the Construct rule, one shared extents walk feeding both metrics and layout), the object sub-column separator sits at one shared x across both lanes, and a tenth bundled theme, **Mockup Slate**, matches the design mockups the release was drawn against.

- **The everyday patterns became rows.** **Has Changed** and **named cooldowns**; **Remember Between Runs**, one right-click toggle that makes a variable survive closing the game (the compiler emits the whole ConfigFile ritual); empty-safe group picking and best-by-property; the State Machine pack telling **Time In State**. A second wave: **Move Toward (smooth)** (frame-rate-independent damping compiled correctly so nobody writes the exp form), **Toggle**, **As Clock Time**, **Every X To Y Seconds**, the 2D distance / aiming / screen-wrap / bob verbs, the **Timeline block** (a schedule as rows compiling to the await-chain you would have written), and the Object Pool's reset seam. A third made game FEEL rows: **coyote time as a condition** (`is_on_floor() was true within 0.1s`), input **press buffering**, the wave director (**On Group Emptied**), decaying knockback, magnet pull, orbit, hold-to-charge, i-frames wired into Health's own damage, burst repeat and floating text. A fourth turned "a mechanic demo" into "a game with goals": **Quest** (`.tres` objectives, chains, journal text one expression away), **Checkpoint** (respawn through the Object Pool's `reset()` seam), **Interaction** (focus the nearest interactable), **Phase Cycle** (day / night with a 0-1 progress) and **Home & Leash**, plus **Only Once Ever** - Trigger Once across runs - and Is Within Distance with five metric geometries. **Compare**, **Working with Values** and **Working with Text** (72 verbs across five new modules) cover what used to mean dropping into an ƒx field - Text Is A Number, natural sort order, Values Are Near - and the **Common Game Patterns** guide maps every one of them to the exact rows that replace the code, with rendered previews.

- **The developer-experience wave: 31 suggestions from one mockup, audited twice.** Once for the condition/action lane and once for the ACE kind on Godot's primitives, so every outcome that HAPPENS is a trigger backed by a real signal with its payload as the row's captured context, every check is a condition, and no debugger information is program text or on by default. Flow: **Wait Until / Wait For All Of / Wait For Any Of** with a deadline and **Wait Succeeded / Wait Timed Out** read back on the next row, **On Failure Of / On Success Of** as triggers any verb can raise with the reason as payload, **Retry Up To N Times** as a looping condition with backoff, throttle / debounce, and **Only Once Per Node / Per Name / This Scene Load** so Trigger Once stops firing only for the first item in a loop. Five packs: **Event Bus**, **Named Scenes** (no `res://` path in a row), **Game Settings** (On Setting Changed with name and value - the exemplar shape), **Debug Overlay** and **Follow A Path**. Services, deferred calls, Spawn Scene As with the node as payload, Watch Data File, value trails and frame budgets, a spatial module, and the Save System's Local-Storage-shaped keys with per-key triggers including **On Save Key Missing**. Then the editor seams: **Row Hit Counts** in the gutter margin (View menu, ships unticked, pixel-identical off), **Why didn't this fire?** listing each condition's verdict from the live values the running game already streams, **Test Sheets** whose claims run headless through Tools > Run Tests or a CLI and print the same summary line the plugin's own suite uses, a **Refactor** menu (Wrap in Condition, Unwrap Event, Inline This Function, Duplicate as Variant, snippets with blanks), **Compare With...** against another sheet or a backup, a **Loose Ends** panel and **Find Repeated Rows** handing the fix to Extract to Function.

- **Save slots, runs and recovery, on the shipped Save System pack.** 39 verbs built ON the existing pack rather than beside it - every existing trigger still fires the same way and every new behavior is inert at its defaults: a load menu without loading the game (Slot Detail, Slot Playtime and a captured thumbnail from a reserved header inside the slot file), an autosave the sheet can veto (**On Autosave Due**, Delay / Pause / Resume, Safe To Save Now), old and broken saves that stop being silent (**On Save Needs Upgrade**), and a Doctor check that reads the emitted scripts and compares what a project READS BACK against what it WRITES, naming a value you expect to persist but never save - counting a write from any route so it never cries wolf. Three editor seams alongside: **Change Type Everywhere** (a variable's type change as one previewed undoable step), **Grid to CSV and back**, and **Paste Special** retargeting copied rows to another object. Two general tool-dev verbs land in the Editor Tools vocabulary - **Render Scene To Image** and **Preview Table Rolls** - plus an **On Project Export** trigger, and **Priced Tables** and **Encounter Timeline** join the fleet: the general priced-interaction table (vendors, kiosks, toll gates, unlock walls) and the general spawn-and-beat timeline (combat waves, boss phases, tutorial pacing), each driven by a `.tres` data asset.

- **Shipping in more than one language - the i18n wave, 21 suggestions.** At runtime: a language menu that builds itself (**For Each Language**, each name in its own language), **Language Matches** and **Region Is** so `en_GB` never fails a hand-written `== "en"`, **Use Saved Language**, **Set Text (follows language)** honest about the engine (an assigned text stops following, so the key is kept and Refresh re-applies), **Counted Text** proven against Russian one / few / many, RTL and font fallback, **Will It Fit** pixel budgets, locale-remapped assets, voice + subtitle pairs, keys in data assets. In the editor: a **Translation Studio**, a Language Variants dialog, pseudo-localization preview, rename-key-everywhere, two Doctor checks pinned against clean cases, and a coverage export gate. Every new builtin string, template, parameter and dropdown label across this whole release is translated in all nine bundled languages - the per-language catalog grew from 624 keys to over 1,700.

- **Documentation you reach without leaving Godot.** Every shipped doc link now goes somewhere: the release zip never carried `docs/`, so the Welcome window's guide button and the README's relative links were all dead in an installed project; links now pin to the released tag from the same version constant this release stamps. Beyond that, an in-editor reader over all three doc sets - the guides, the 77 addon guides and **36 new module guides over all 48 builtin modules** (about 700 core verbs that had no guide at all) - opens from Tools > Documentation, F1, or the `?` prefix in the command palette, with a tree beside a natively rendered page. **Explain This Row** answers for any row. Figures draw themselves: an authored ```eventsheet fence always wins, an auto-detected gate-passing ```gdscript block becomes a live figure, `<!-- no-figure -->` opts out, and the whole reader follows the restrained **Compact Developer** chrome without touching the sheet preview. `docs/GUIDE-WRITING-THE-DOCS.md` explains how all of it works and how to add to it.

- **The authoring loop closes.** **Ghost Row Part II**: suggestion chips before you type (your most-used verbs of that kind, the featured ones until habits exist), one click applying a verb with its first parameter open, and learn-as-you-type ranking from every successful apply. **Recent values per parameter** (the last five committed values, one pick instead of a retype). A sticky **group breadcrumb** on 1,000-row sheets, **View > Compact Rows** (10.9% more rows on screen, whitespace only - text and dialogs never shrink), the **Picker Preview** rail answering how your verbs will read in the picker before you save, **Sheet > Publish New Version** (patch / minor / major with a one-line note as a doc comment), the addon guide scaffolder with every factual section pre-filled from the script, node-drop onto the Sheet Type dialog, the inline colour picker's saved palette, and the **Self section** - C3's `Self.` reflex in the Expressions dictionary across all four tiers, down to the running game answering with the behaviours actually attached at runtime.

**Quality:** every feature landed suite-green with byte-exact round-trip gates and `drifted=0` across all **91 packs**; the corpus test opens real sources, so a lift regression on hand-written code cannot pass unnoticed. Every wave-1 verb is pinned at its emitted line AND run at runtime, every trigger's test connects to its signal and asserts the payload, and every refactor asserts undo restores the sheet byte for byte. Two independent adversarial reviews (the interop stack, the v0.16 release notes themselves) drove fixes rather than reassurance: 21 defects in green-suite code, and three wrong countable claims re-derived from the code. Two hardening fixes worth naming: the plugin's chrome now tracks the editor display scale on Retina Macs (the v0.16 fix covered row text only), and opening a sheet no longer spams the Output dock once per drawn row. The one perf regression found this cycle was pre-existing - the addon listing rescanned ~90 pack folders per keystroke and passed only on lucky timing - and is cached on directory modification times. Generated code still never depends on the plugin, emission stays deterministic, and everything is verified on Godot 4.7 stable.
