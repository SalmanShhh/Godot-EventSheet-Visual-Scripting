# v0.16.0 - Open Anything, Publish Anything & Ask What Is There

This release is about the round trip. **Open Anything**: `.gd` is the default sheet format, so this release taught the importer to claim far more of the language - `match`, or-blocks, `static`, `@rpc`, doc comments, setter/getters, compound assignments, and the blank lines real code is full of - and taught the canvas to draw a pack's own published verbs, triggers and language constructs in the same two lanes as every other event. **Publish Anything**: point the ACE wizard at a script you already own and it previews what that script will publish, lets you curate it in place, and writes the decision back as `## @ace_*` comments without touching a signature; one public `publish_pack` pipeline now powers the bundled builders and Sheet > Export Addon alike. **Ask What Is There**: 88 raycasting verbs across both dimensions, two labs that draw every cast live, and Stepping so a fast mover stops tunnelling through walls. The pack count grows from 70 to **76**, the native vocabulary passes **925 ACEs**, everything still compiles to plain typed GDScript with zero runtime dependency, and every pack round-trips byte-for-byte.

## Highlights

- **Everything reads as an event row - including the pack itself.** A behaviour pack's published verbs used to render as a flat spec table and its triggers as a bare `signal` strip. Both now use the same two lanes as every other event: the condition lane carries the kind badge, the verb name and one typed chip per input (`id  text`, `seconds  number`, `reset instantly  true/false`); the action lane carries what the name cannot tell you - category, `gives back <type>`, `waits` / `static` / `internal` / featured, and the step count. The `## @ace_description` you already wrote round-tripped through the compiler for releases but was never drawn; it now renders as a muted caption welded above its verb. GDScript types read as plain words, the raw `func name(params) -> Type` tail is gone, verb bodies are open on sight as ordinary sub-events, and verbs are spliced in the file's own order so an opened pack reads top-to-bottom like its `.gd`. Authoring moved onto the row with them: double-click the name, the caption or the category chip to edit in place (each writing an `## @ace_name` / `## @ace_description` / `## @ace_category` line a programmer can still set by hand), a parameter is a cell that opens a small Edit Parameter dialog rather than the whole verb form, and right-click > New Function > Action / Condition / Expression opens the dialog with that kind already picked. Nine new theme tokens make all of it themable, and all nine bundled themes dress verbs in their own palette with the meaning held constant: Action warm, Condition green, Expression violet.

- **A hand-written `.gd` opens as editable rows, not a wall of code.** A `match` becomes a structured switch/case whose pattern editor autocompletes to the switched variable's enum members; `if a or b:` splits into a Construct-style Or block; `break` / `continue` become Break Loop / Continue Loop; compound assignments reverse-lift (`$Sprite.modulate.a -= fade` to Subtract From Property), with a more specific verb still winning wherever one exists, so `self.position += velocity` reads as Move By rather than Add To Property; and `static var`, `static func`, a function carrying `@rpc`, a `##` documentation comment, a setter/getter property, a multi-line enum and an inferred local `const` all open as editable rows. The one that mattered most: a single blank line between two statements used to collapse an ENTIRE function to a gray verbatim wall, and paragraph breaks are near-universal in real Godot code, so ordinary documented `_ready` / `_process` handlers opened as walls instead of events. They now read as clean condition/action rows with your spacing preserved. What is still not an event reads as a browsable language block rather than a code blob: a pure-data `class X:` folds open to `name : type = default` field rows you edit in place, a methods-bearing inner class lists `ƒ name(params) -> Type` chips, a pack's `_enter_tree` boilerplate reads as a Host binding block, and a lone helper collapses to a `ƒ` row with an "N lines" cue. Every lift is gated by a byte-exact recompile, so anything the model cannot reproduce degrades to a verbatim block instead of corrupting your file.

- **Point the wizard at your own script: preview it, curate it, and survive a rename.** Sheet > Custom Actions… now reports every verb a script will publish before you commit - kind, picker label, parameters, the exact emitted code - plus warnings phrased as the fix (an untyped `func is_ready():` publishes as an Action, not a Condition; no `class_name` means the id comes from the file name). That table is now the editing surface: Publish / Kind / Verb / Category are editable in place, and **Curate Script…** writes only the DIFFERENCES back as `## @ace_*` comment lines - your signature and body are never rewritten, the file is backed up first, re-curating replaces rather than accumulates, and annotations the wizard does not own are preserved. **Parameters…** shapes a verb's hints, `value=Label` choices and starting values. **Keep Old Name…** closes the rename hole by appending a deprecated forwarding stand-in of the previous name, hidden from the picker - the only construct that could work, since a compiled `.gd` holds call text and no id at all. Backing it up, a new **orphaned-verb** Doctor check reads the emitted CALLS rather than sheet models and flags a call to a provider member absent from its own API, its inheritance chain and its engine base: the one failure here that compiles green and breaks at game runtime.

- **An `@ace_param` author can finally say everything a bundled module can.** `default:` sets what a row shows the moment it is dropped, falling back to the method's own GDScript default, so `func fire(power: float = 25.0)` lands in the picker already reading 25.0 instead of 0.0. Option lists take `value=Label`, so a dropdown reads as English while inserting the real token. And `hint: comparison` is the whole `=` / `!=` / `<` / `<=` / `>` / `>=` dropdown in one word, labeled in plain English and seeded to `==`. The same shapes reach the public API through `EventSheets.param_spec()`, `combo_options()` and `comparison_options()`, which `simple_ace()` and `simple_block_kind()` run every parameter through. Inspector table columns learned labels too, so a data grid can offer ">= (at least)" while the cell stores the short token its runtime matches on. And any numeric parameter is now **scrubbable**: drag its label sideways to tune it, Shift for fine and Ctrl for coarse, with the step following the value's own magnitude so a bullet speed of 3000 and an alpha of 0.5 both move usefully under one gesture.

- **Every kind of raycast, in both dimensions - 88 new verbs and two labs that draw them.** A RayCast node could be READ but never AIMED, ShapeCast was missing entirely, and 3D had no point query and no volume query. Now: RayCast2D/3D aiming, masking and exceptions (Point RayCast At, Ignore Node, Hits From Inside, RayCast Hits Group, Hit Face Index); the whole swept ShapeCast2D/3D family including Safe Fraction, for moving right up to a wall; **Cast Ray Into**, which fires ONE cast and stores the result so the Ray Result verbs read collider, point, normal, shape, face and group for free instead of re-casting per question; Query Bodies At Point / In Sphere / In Box / Under Mouse; Cast Circle and Sphere Motion Into; and Cast Ray From Mouse Into, which makes click-to-select in 3D a single row. Two showcases make a cast VISIBLE, which is exactly what you never had when a ray "does not work": **Raycast Lab** runs six casts at once and **Raycast Lab 3D** runs seven, each traced back to the question that produced it - drawn and colour-coded in the room, with the 3D lab's box and point queries reported in the readout - every one built from the SHIPPED descriptor so a lab cannot drift from the vocabulary. Alongside it, **Stepping** lands on Bullet, Bullet 3D, Move To, Move To 3D and Follow: a bullet at 3000 px/s jumps about 50 pixels a frame, so a 20-pixel wall can sit entirely between where it was and where it lands. Stepping sweeps the frame's motion instead of teleporting along it, stops at the exact contact point and reports what it struck. Off by default, and the non-stepping path is the original two lines untouched.

- **One publish pipeline, and packs that carry their own identity.** `EventSheets.publish_pack(sheet, base_path, icon_path)` is the whole pack pipeline in one public call, and the bundled builders' `save_pack` is now a thin wrapper over it, proven by a byte-identical rebuild of every pack. Sheet > Export Addon… publishes through that same pipeline, so a user's exported addon gets the same lifts, stable uids and icon detection, and reads exactly like a bundled pack when reopened. Six Construct-SDK seams arrive as plain annotations and duck-typed methods with no base class anywhere: `@ace_version` / `@ace_author` / `@ace_help` identity, `@ace_requires` dependencies with a Doctor check that stays silent on an unused pack, `@ace_looping(iterator)` turning a collection-returning method into a For-Each condition that reuses the existing loop lane, `static func editor_gizmo_draw()` for a live viewport overlay while the node is selected, `debugger_properties()` streaming a behaviour's own section into the Live Values panel, and per-pack translations.

- **A Construct user's reflexes now work.** Else leads its condition lane with a "System | Else" chip like any other condition and stops redrawing the trigger a C3 Else never repeats, and Make Else / Make Else-If moved from the Expert-only submenu to the top level of the right-click menu - including Simple Mode, the first-run default, where a Construct user could previously never find them at all. The object column is aligned by default so a sheet scans as a table, and dragging any lane boundary draws one continuous guide line through the whole sheet. `loopindex` lands on For Each, Repeat and While (0-based even over an offset `range(2, 8)`), plus Loop Index Of for reading a named outer loop's counter from inside a nested one, and it is pure opt-in so existing output is byte-unchanged. The whole C3 keyboard grammar works key for key, event numbers live in the margin and stay stable through folding, and Bookmarks, the Outline panel, the filter lens, Replace Object References, batch param edit, cell navigation and session restore all landed on the C3 model.

- **Build editor tools and data assets without writing a line.** Sheet > New Editor Tool… scaffolds a ready-to-run editor-side sheet in one click, and the Doctor catches the classic first mistake by nudging a tool sheet that adds, removes or reparents nodes without registering undo. Sheet > New Custom Resource… builds a data asset from three plain questions and emits a Resource-host sheet whose Inspector IS the fill-in grid, `.tres`-ready, with a live "Ships as" receipt. `EventSheets.resource_grid()` owns that payload, `attach_validator()` gives a variable live Inspector validation in one call, and naming a function in the new Inspector button field ships it as a one-click `@export_tool_button`.

- **Rounding it out.** **Compare** (31 ACEs) covers what used to mean dropping into an ƒx field - text blank meaning empty OR only spaces, wildcard match, natural order so "item2" sorts before "item10", Values Are Near with a tolerance because `==` on floats is a coin flip after any arithmetic, and Object Still Exists, since a freed node is not null. **Nodes: Activation** (23 ACEs) makes pausing per-node instead of whole-game, with Node Is Running answering through `can_process()` so it accounts for both the node's mode and the game pause. **Array** gained Filter / Map / Reduce / Any Match / All Match with the element name as a field rather than baked into the template. Seven builtin modules land at once - Mesh, Gradients & Curves, Camera FOV, Animation, Audio Server, Physics Server and Rendering. The editor ships **8 translations** (French, Spanish, German, Italian, Korean, Japanese, Russian and Simplified Chinese) at 624 filled keys each, so the Language picker offers **nine languages** counting English as the built-in source; translations stay drop-in and hot-reload on the next filesystem scan, and the words drawn ON the canvas were translated for the first time - they are painted rather than Controls, so Godot's auto-translation never reached them.

**Quality:** every feature landed suite-green with byte-exact round-trip gates and `drifted=0` across all **76 packs**; the byte-identical rebuild of every pack is what proves the single `publish_pack` pipeline. A whole-plugin review and a 15-finding ultra-review drove a hardening pass whose findings were not cosmetic: generated GDScript is now written through a temp file plus rename with a read-back check (opening the target truncated it FIRST, so a crash mid-write could leave a sheet zero-byte), the backup ring now covers `.gd` sheets (it filtered to `.tres`, so those backups were invisible to Restore), and every picker-authored On Signal event was dead code because the trigger's values were never baked onto the row. Three parity holes that reported a SUCCESSFUL compile of code Godot refuses to load are closed: a `Vector3` variable emitted the bare tuple `(0, 0, 0)`, an "On node" target could emit `$Node.not thing.is_empty()`, and the Custom Block byte gate was voluntary - it lived in a helper a kind called on ITSELF, so the importer now re-verifies every claim. The gates themselves were hardened: the runner could print `All tests passed.` while a test file failed to load, and the pack drift audit always exited 0 while skipping root-level single-file packs. Behaviour is proven by runtime smokes rather than inspection - two 6000 px/s bullets at a 10px wall, stepping off ending straight through it and stepping on stopping at the wall's near face. Generated code still never depends on the plugin, emission stays deterministic, and everything is verified on Godot 4.7 stable.
